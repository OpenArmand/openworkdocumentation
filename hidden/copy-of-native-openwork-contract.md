# Copy of Native OpenWork Contract

The below table describes all the user facing functions that the contract will have. Note that there might be some internal functions needed apart from this.



| Feature                                                                                                                                | Implementation                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Users should be able to create a profile and retrieve it                                                                               | <p>Struct :</p><p>Profile {address, ipfs_hash, referrer_address, rating} </p><p><br>Functions:<br>setProfile(ipfsHash)<br>getProfile(address)</p>                                                                                                                                                                                                         |
| Users should be able to post a job                                                                                                     | <p>Struct :<br>Job {id, jobGiver, applicants:[], jobDetailHash, isOpen, workSubmissions:[], milestonePayments:[], totalPaid, currentLockedAmount, currentMilestone,selectedApplciant }<br><br>Functions:<br>postJob(ipfsHash, milestones) { setJobDetailHash() setmilestonePayments()<br>setIsOpen() }</p>                                                |
| Users should be able to apply to a posted Job                                                                                          | <p>applyToJob(jobID, application_hash) {<br> getJobDetails() <br>isOpen()<br>addApplicant(jobID)<br>}</p>                                                                                                                                                                                                                                                 |
| Job Giver should be able to select an applicant and start a job                                                                        | <p>startJob&#x26;LockMilestone1(address) {<br>getJobDetails() <br>isJobGiver? <br>Lock first milestone 1 amount <br>addSelectedApplicant()<br>}</p>                                                                                                                                                                                                       |
| Job Givers calling through another chain should be able to lock the funds on their local chain and start the job on the OpenWork Chain | <p>startJobInterChain (applicationID) { <br>getJobDetails() <br>isJobGiver? <br>addSelected Applicant <br>}</p>                                                                                                                                                                                                                                           |
| Job Taker should be able to submit work                                                                                                | <p>submitWork(submissionHash) { <br>getJobDetails() <br>isApplicant() <br>addWorkSubmision() <br>} </p>                                                                                                                                                                                                                                                   |
| Job Giver should be able to pay for a milestone and lock next milestone amount                                                         | <p>release&#x26;LockNext(jobID){ <br>isJobGiver?<br>getCurrentMilestone()<br>Send current milestone payment to jobTaker <br>Increment milestone by 1 <br>Call Earnings and Rewards contract and Set rewards <br>Lock next milestone amount (if last milestone, ignore this step) <br>Update totalJobValue [totalJobValue will be a mapping] <br>}<br></p> |
| Job Giver on another chain should be able to pay on their local chain and update the data on this chain                                | <p>release&#x26;LockNextInterchain(jobID) { <br>isJobGiver?<br>getCurrentMilestone<br>increment milestone by 1 <br>call Earnings and Rewards contract and set rewards Lock next milestone amount <br>update totalJobValue }</p>                                                                                                                           |
| Job Giver should be able to pay for a milestone and terminate a job                                                                    | <p>release&#x26;terminateJob(jobID) {<br> isJobGiver?<br>getJobDetails <br>getCurrentMilestone(jobID)<br>release current milestone payment <br>call Earnings and rewards contract and set rewards update totalJobValue }</p>                                                                                                                              |
| Job Giver on another chain should be able to pay on their local chain for a milestone and terminate a job                              | <p>release&#x26;terminateJobInterChain(jobID) {<br> isJobGiver?<br>getJobDetails <br>getCurrentMilestone(jobID)<br>call Earnings and rewards contract and set rewards update totalJobValue }</p>                                                                                                                                                          |
| Job Giver/Taker should be able to rate each other on a job                                                                             | <p>rate (jobID, address) {<br> if caller is associated with the job add the rating to the profile }<br>getRating(address)</p>                                                                                                                                                                                                                             |
| Main DAO contract should be able to upgrade the contract                                                                               | upgrade(newImplementation)                                                                                                                                                                                                                                                                                                                                |
