# Voting Power Calculation

This table describes the staking and unlocking/redeeming logic for all types of token

| Type of Token           | Stake Period                                                    | Pre-Staked? | Governance Action Required                                            | Governance Power                |
| ----------------------- | --------------------------------------------------------------- | ----------- | --------------------------------------------------------------------- | ------------------------------- |
| Earned Tokens           | see [Rewards Table](../smart-contract-details/rewards-table.md) | Yes         | Yes (see [Rewards Table](../smart-contract-details/rewards-table.md)) | 1x                              |
| Voluntary Staked Tokens | 1, 2, or 3 years (user choice)                                  | No          | No                                                                    | 1x, 2x, or 3x based on duration |
