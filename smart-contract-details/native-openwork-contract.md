# Native OpenWork Job Contract

This table describes all the features this contract will have and how they will be implemented.&#x20;

| **Feature**                              | **Implementation Details**                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Profile Management**                   | <p><strong>Struct:</strong> <code>Profile { address, ipfs_hash, referrer_address, rating }</code><br><strong>Functions:</strong><br>• <code>setProfile(ipfsHash)</code> – Stores user profile data on-chain<br>• <code>getProfile(address)</code> – Retrieves the profile for a given address</p>                                                                                                                                                                          |
| **Job Posting**                          | <p><strong>Struct:</strong> <code>Job { id, jobGiver, applicants:[], jobDetailHash, isOpen, workSubmissions:[], milestonePayments:[], totalPaid, currentLockedAmount, currentMilestone, selectedApplicant }</code><br><strong>Function:</strong><br><code>postJob(ipfsHash, milestones) {</code></p><p><code>setJobDetailHash()</code>, <code>setmilestonePayments()</code>, <code>setIsOpen()</code><br><code>}</code><br><br><code>Note:</code> Max. 10K USD per Job</p> |
| **Job Application**                      | <p><code>applyToJob(jobID, application_hash)</code> {</p><p><code>getJobDetails()</code></p><p><code>isOpen()</code><br><code>addApplication(jobID)</code> <br>}</p>                                                                                                                                                                                                                                                                                                       |
| **Job Initiation (Direct)**              | <p><code>startJob&#x26;LockMilestone1(address)</code> {<br><code>getJobDetails()</code><br><code>isJobGiver()</code><br><code>LockPayment()</code><br><code>addSelectedApplicant()</code><br><code>}</code></p>                                                                                                                                                                                                                                                            |
| **Job Initiation (InterChain)**          | <p><code>startJobInterChain(applicationID)</code> {<br><code>getJobDetails()</code><br><code>isJobGiver()</code><br><code>addSelectedApplicant()</code><br>}</p>                                                                                                                                                                                                                                                                                                           |
| **Work Submission**                      | <p><code>submitWork(submissionHash)</code> {<br><code>getJobDetails()</code><br><code>isApplicant()</code><br><code>addWorkSubmission()</code><br><code>}</code></p>                                                                                                                                                                                                                                                                                                       |
| **Release Current Milestone Payment**    | <p><code>releasePayment(jobID){</code></p><p><code>isJobGiver</code></p><p><code>getCurrentMilestone()</code><br><code>makePayment()</code><br><code>incrementMilestone()</code><br>Call  <code>setRewards()</code> on the Earnings &#x26; Rewards Contract <code>updateTotalJobValue()</code><br>}</p>                                                                                                                                                                    |

| **InterChain Lock Next Milestone**       | <p><code>LockNextMilestoneInterchain(jobID)</code> {<br><code>updateJob(jobID)</code><br>}<br><br>Note: Payment is locked in local chain.</p>                                                                                                                                                                                                                                                                                                                              |
| **Rating System**                        | <p><code>rate(jobID, address)</code> </p><p>Allows a job giver/taker to rate each other (only if the caller is associated with the job)<br><code>getRating(address)</code> </p><p>Retrieves the rating for a specified address</p>                                                                                                                                                                                                                                         |
| **Adding Portfolios**                    | <p><code>AddPortfolio(address)</code> <br>Adds a portfolio hash to the given profile</p>                                                                                                                                                                                                                                                                                                                                                                                   |
